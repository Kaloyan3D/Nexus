# Offline lifecycle boundary review

Scope: fake transport only, full deterministic initialization/stages/checkpoint/arms/collection/grading/reporting and crash recovery. This does not enable an official benchmark or certify natural CP-500.

1. Truth: fake transport's contiguous durable events and flushed receipt own simulated submissions. Production decoder/pressure/wire functions read these events unchanged. Simulated usage is explicitly labeled, never promoted to provider evidence.
2. Ownership: harness writes release/journal/checkpoint/restore/collection receipts; fake transport writes session/binding/producer state and the positive-control source repairs. Only persistence of intent/provenance controls retransmission. Human Git identity remains unchanged.
3. Direction: rehearsal imports benchmark and frozen infrastructure; nothing in production imports rehearsal. Live calibration cannot consume a simulation-marked root.
4. Boundaries: branded immutable fake transport; deterministic JSON journals and content-free reports. No arbitrary transport or provider credential is accepted. Snapshot authority covers workspace, fixture commit, session/task, obligations, T99 and durable prefixes.
5. Failures: submission keys are idempotent in the fake endpoint. A durable absent RPC may resume only because the fake receipt store proves absence; the real runner remains fail-closed on ambiguous intent. Corrupt journals/receipts/seals or conflicting sources block.
6. Lifecycle: initialize via existing offline preparation; create deterministic fixture Git commit; release/repair/inspect/flush/grade each phase; atomically publish simulated CP-500; restore the same canonical workspace for each arm; T99/collect/grade; produce independent verdicts. Partial checkpoint/restore work resumes only from validated owned staging/markers, never uncertain completed flags.
7. Test seams: fake usage and time are fixed; fault hooks throw at defined transitions. Actual grader, decoder, activation and wire authorities are used. No timing sleeps or RPC/network server exists.
8. Compatibility: existing calibration remains six phases. Simulation lives under separate roots and markers; old contract roots require reconstruction. Snapshot excludes Git implementation cache files but includes fixture commit/tree and all benchmark authority bytes. Restores keep the same absolute workspace namespace; Git objects and refs stay fixed across arms.
9. Observability: request telemetry marks SIMULATED; report emits only NOT_MEASURED for capability/benefit/safety and INADEQUATE for live workload validity. Offline lifecycle correctness is separate from those verdicts. Source/inventory checks and exact hashes detect drift.
10. Security: require the offline network/child-process blocker and branded fake transport. Live startup rejects simulation roots. Morning calibration requires a nonexistent new root, uses pinned Node, and stops at six phases. Hidden expected answers remain in host grading; T00 deliberately establishes visible engineering constraints, while later prompts/T99 do not enumerate hidden grader expectations.
