# Bounded host grading observation

Official run10's E21 cumulative observation returned `grading-failure` without a named failed case. An independent diagnostic of the same prefix completed with every row passing in 39,201 ms, longer than the observer's 30,000 ms allowance. The original child exit metadata was discarded, so its precise exit cause is not proven. This is an observation-budget defect: a valid supported prefix needs longer than the allotted deadline. The interrupted attempt remains diagnostic only and is never resumed or promoted.

Cumulative, official final and standalone CLI grading now share a bounded 300,000 ms host observation allowance. The workload has grown to 42 engineering phases and its final integration, while the former allowances were 30,000 or 60,000 ms. The new allowance provides room for full cumulative evaluation and normal host variation. It does not change the VM's 1,000 ms execution limits, cases, oracle, mutations, source protection, obligation thresholds, provider validity or model-turn budgets. Unavailable grading remains fail-closed. Cumulative failures retain the child's real exit status, signal and error code so future deadline failures are distinguishable from failed correctness rows.

Two deterministic regressions failed before the fix: a valid child result available after the observed 39,201 ms was rejected by the old limit, and actual timeout metadata was discarded. Both pass after the fix. The existing CLI unavailable-worker regression still requires failure and a sanitized environment; only its observation allowance changes to match the expanded workload.

Production owns candidate execution and durable telemetry. The host owns independent oracle evaluation; its observation allowance must accommodate the frozen finite test set. This change adds no state machine, resume, retry or authority. The calibration contract changes because its observer source changes, so a fresh live calibration and a fresh official root are required. Workload and frozen production remain unchanged. Tests run against the new source; the interrupted previous suite is reported as incomplete.
