# Idea: "Pomodoro Focus" — a single-page focus timer

## Goal
A small static web app that helps people work in focused 25-minute blocks.

## Requirements
- One `index.html` file with inline CSS and inline JavaScript (no build step, no dependencies).
- A large countdown timer (25:00 default) with Start, Pause and Reset buttons.
- A mode switch: Focus (25 min), Short break (5 min), Long break (15 min).
- A counter of completed focus sessions for the current page visit.
- When a timer reaches zero, show a visible "Time's up" message and change the page background color.
- Clean, modern look; readable on a phone and on a laptop.

## Done when
- `index.html` exists in the project folder and works by opening it in a browser.
- A short `README.md` explains what it is and how to open it.
