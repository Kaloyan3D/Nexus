# Runbook — first real GUI coding task on an independent project (A6.1 final acceptance)

**Status: PREPARED, NOT RUN. This runbook needs your fresh, explicit authorization at step 6.** No provider request has been made for A6.1.3, and the earlier single-use records authorize nothing here. The preparing agent does not start the Desktop, does not run the approver and will not create the authorization record.

Provider: OpenCode Go only (`opencode-go-native` / `muse-spark-1.3-contributor`). Fish shell.

## 0. Pick the project (you)

* A real **non-Nexus** Git project, ideally Rust (or TypeScript with committed, offline-usable `node_modules`), that you are willing to send *non-secret* source excerpts of to the provider (see the disclosure statement printed by `nexus project show`; reads cannot be path-scoped).
* Its tests run **offline** and pass or fail deterministically with `cargo test --offline` (or `npm test`). Dependencies: Rust crates must be in the admitted cache (`nexus tools depcache admit …`, then `--dep-cache`).
* A task that needs **several files** and more than one test iteration (for example a bug whose fix spans two modules plus a regression test). A one-line synthetic bug is only a smoke test.
* A clean tree at the commit you want pinned: `git -C <repo> status --porcelain` is empty.

## 1. Register (operator terminal A)

```fish
cd ~/Projects/Nexus
cargo build --manifest-path native/Cargo.toml
set -x A54_HOME $HOME/.nexus-a54
set -x NEXUS_PROJECT_REGISTRY $A54_HOME/projects
native/target/debug/nexus project add myproj ~/work/myproj --write-allow src/,tests/
native/target/debug/nexus project show myproj          # read the pin, write scope, restrictions and disclosure
```

Write scope: only paths you are happy for the model to propose edits to. Leave out build files; `Cargo.toml`, lockfiles, `build.rs`, CI, hidden and credential-shaped paths are protected regardless.

## 5. Write the task (one line, no trailing newline)

Name the symptom and the allowed files; tell the model to read first, propose edits one at a time, run the offline test after each, and to stop on a pass. Save it:

```fish
printf '%s' '<your one-line task>' > $A54_HOME/gui-task.txt
wc -c < $A54_HOME/gui-task.txt; sha256sum < $A54_HOME/gui-task.txt | cut -d' ' -f1   # must equal the bytes/sha256 the Desktop shows for the pasted text
```

## 6. ⛔ Authorization (the point of no return — only after you decide to run)

```fish
native/target/debug/nexus-broker authorize-live-session --state-dir $A54_HOME/broker \
  --intent-type repo-code --provider opencode-go-native --model muse-spark-1.3-contributor --workspace myproj \
  --prompt-file $A54_HOME/gui-task.txt --max-turns 12 --max-tool-calls 30 \
  --max-output-tokens 1024 --max-tool-result-bytes 131072 --expires-in-secs 1800 --acknowledge-billable
```

The record is single-use and consumed by the first submission, even a refused one (a one-byte difference in the pasted text).

## 7. Run and approve (terminal B, yours only)

```fish
set -l AP native/target/debug/nexus-approver --socket $A54_HOME/daemon/n.sock
$AP list
$AP --cap-file $A54_HOME/daemon/approver.cap review <APPROVAL_ID>
```

Approve only edits to files you expect and only `cargo test --offline` (or `npm test`). Deny anything else. Expect: reads, an approval banner per edit/command, a failing test, a correction, a passing test. Watch for: the **verified outcome** (not the model's words) saying tests passed with the last test after the last edit; "stale" if you approved an edit after the last pass.

## 8. Review, keep or discard

* Desktop: **View diff**, **Test output**, **Evidence**; **Copy patch** (explicit click).
* Operator: `nexus-broker worktree list …`, `nexus-broker worktree patch <run-id> … --out ~/myproj.patch`, then **you** apply it to your repository (`git apply --check` first) — Nexus never does.
* Reconnect check: quit the Desktop completely, start it again; the run, outcome and diff must be there.
* Original check: `git -C ~/work/myproj status --porcelain; git -C ~/work/myproj rev-parse HEAD` must equal `$A54_HOME/proj-before.txt`.
* Cleanup (explicit): `nexus-broker worktree remove <run-id> … --yes`; the outcome and receipts remain.
