# A5.5 live acceptance runbook — read-only repo-inspect on OpenCode Go

**Status: BLOCKED until you create the session authorization below.** Nothing in A5.5 has contacted the real provider with tools. The A5.4 key, its Registry route verification and its single-call authorization records do **not** authorize this: a `repo-inspect` run makes several billable provider calls whose later bodies carry repository text.

## What one authorized session exposes

* Provider/model: `opencode-go-native` / `muse-spark-1.3-contributor` only. Endpoint pinned to `https://opencode.ai/inference/go/openai/v1/responses`. No fallback, no retry.
* Up to **N billable POSTs** (one per model turn; N = `--max-turns`). Each has `max_output_tokens` ≤ the per-call ceiling you set. Each is stateless: it re-sends the task text, the model's own earlier tool calls and every tool result so far.
* **Repository bytes sent to the provider:** only what the three read-only tools return, redacted by the native tools, hidden/VCS/credential paths blocked, each result ≤ 24 KiB and all results ≤ `--max-tool-result-bytes`. The workspace for this test is the synthetic repository created below (no credentials, no private content).
* Tools offered: `fs_list`, `fs_read`, `fs_search` only (catalog digest recorded). Nothing is written or executed; the Kernel independently refuses any non-read or non-`repo-inspect` call.
* Unconfirmed against the real provider: the **streaming** shape of OpenAI-Responses function calls on OpenCode Go (event names, `call_id` placement). Route verification only proved a non-streaming `function_call` with a `call_id`. The first live session is the confirming experiment; a protocol mismatch ends the run as `failed` with no tool executed and nothing re-sent.

## Commands (you run these)

```sh
cd ~/Projects/Nexus
export A54_HOME=$HOME/.nexus-a54
cargo build --manifest-path native/Cargo.toml          # nexusd, nexus-broker, nexus must be the new build
sh native/deploy/a54-dev-instance.sh stop               # restart onto the A5.5 binaries
sh native/deploy/a54-dev-instance.sh synthetic-repo     # once: $A54_HOME/inspect-repo (synthetic sources only)
export A55_WORKSPACE=demo=$A54_HOME/inspect-repo        # ONE read-only workspace
sh native/deploy/a54-dev-instance.sh start
sh native/deploy/a54-dev-instance.sh check              # must print "runs the installed binary"

printf '%s' 'Find the function that authorizes model execution in this repository, list every place that calls it, and cite file:line for each claim.' > $A54_HOME/inspect-task.txt

native/target/debug/nexus-broker authorize-live-session --state-dir $A54_HOME/broker \
  --provider opencode-go-native --model muse-spark-1.3-contributor --workspace demo \
  --prompt-file $A54_HOME/inspect-task.txt --max-turns 6 --max-tool-calls 8 \
  --max-output-tokens 1024 --max-tool-result-bytes 65536 --expires-in-secs 900 --acknowledge-billable
```

Then say "authorized". The agent submits **once** with exactly:

```sh
native/target/debug/nexus intent submit --type repo-inspect --workspace demo \
  --input $A54_HOME/inspect-task.txt --max-turns 6 --max-tool-calls 8 \
  --max-tool-result-bytes 65536 --max-output-tokens 1024 --follow --json
```

Run limits can only be equal to or tighter than the record; a larger value, a different workspace, a different task text or a missing `--max-output-tokens` is refused before any grant exists (and still consumes the record).

## Safety properties

* The record is `0600`, create-new, consumed by rename once, before any grant is minted. Expired, loose-permission, mismatched or reused records refuse with nothing sent. A5.4 single-call records are a different file and never satisfy a session.
* A restarted broker never resumes a run (`loop-interrupted` / `uncertain`), so a restart cannot repeat a tool or a provider call; a stale broker binary refuses to spend the authorization (`broker-stale`, record kept).
* Cancellation (`nexus intent cancel <runId>`) stops the in-flight request and every later step; nothing is re-sent.
