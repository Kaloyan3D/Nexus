## 8. Defects found by the live run, fixed, re-verified
1. **Sandbox without `localhost`** — network-off sandbox had no hosts file, vitest failed before running any test. Fix: a minimal sandbox-owned `/etc/hosts` (`nexus-tools/src/process.rs`). Re-verified live (run 3 ran vitest in Nexus) + test `an_offline_command_resolves_localhost_from_the_sandbox_own_hosts_file`.
2. **Long commands reported "uncertain"** — broker read timeout for `proc_run` was 150 s although the workbench allows 15 min; slow `npm ci/install/typecheck` looked like a lost daemon. Fix: timeout follows the request's sealed wall budget (`inspect.rs`). Not separately re-observed live (later runs were fast); covered by existing process tests only.
3. **Findings index overwritten by a status answer** — a read-only answer that re-listed F2…F10 renumbered the index (seen in conversation A after run 5: F1's title became the answer's heading). Fix: renumber only when the request names no existing finding; E2E assertion added. **The stored index of conversation A still carries the damage** (an attempt to repair the live store by hand was blocked by the permission system and was not retried); runs 1–5, their answers and receipts are intact.
4. **Every task re-snapshotted the project** — the change detector hashed files the snapshot skips (>4 MiB PDFs), so every run reported "project changed" and went down the rebase path (and older patches could not be adopted). Fix in `snapshot.rs` + unit test. Re-verified live: a new question did not create a new snapshot (`…-10` stayed latest).
5. (minor) `finding_head` dropped a leading backtick from titles — fixed with a test.
